# Welcome: a new site, a new notebook

This site is intentionally simple: a single HTML shell, a handful of markdown files, and nothing else. No CMS, no database, no build pipeline. Every page you'll read — the about page, the publication list, the CV, this very post — is a plain text file living in a GitHub repository.

## Why markdown-first?

Writing is the bottleneck for most academic blogs, not publishing. If the distance between "idea" and "published post" involves logging into a dashboard, formatting with a mouse, and fighting a rich-text editor, posts simply never get written.

So the rules here are:

1. **Every post is one markdown file.** Write it anywhere, even on paper first.
2. **Publishing means committing a file.** If it's in the `/blog` folder, it's live. No registration step, no index to update.
3. **The site should be boring to maintain** so that writing stays the interesting part.

## What to expect

Notes on research in progress: papers I'm reading, methods I'm testing, negative results that deserve a home, and the occasional longer essay on how science gets done. I'll also post release notes when code or datasets from my group go public.

> Short version: treat this as a public lab notebook, not a polished magazine.
