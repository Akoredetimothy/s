# Dive into Deep Learning

The D2L book by Aston Zhang, Zachary Lipton, Mu Li, and Alex Smola teaches deep learning through executable code, pairing each concept with a runnable example and its mathematics.

## What it covers

- From scratch implementations of core building blocks (autograd, linear/convolutional/recurrent nets)
- Modern topics: attention, transformers, optimization, computer vision, NLP, recommender systems
- Every chapter ships as a Jupyter notebook

## Takeaway

The best "learn by building" resource. Reading code alongside equations makes the gap between math and implementation vanish.
